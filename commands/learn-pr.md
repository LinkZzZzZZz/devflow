Разбери замечания ревьюеров к моим PR и предложи, чему научить плагин: $ARGUMENTS

Справочник — `${CLAUDE_PLUGIN_ROOT}/skills/resolve-pr-comments/references/learn.md` (журнал §1, ключи §2, бриф классификации §3, порядок сверки §4, формат кандидатов §5). Работай из сессии в каталоге проекта: `gh` берёт репозиторий из текущего каталога. Нет `.claude/workflow.md` — репозиторий берётся из URL PR. На GitHub и в YouTrack ничего не пиши.

1. **Источники PR.** Аргументы: ссылки на PR, ключи тикетов (PR — `gh pr list --head <KEY> --state all --json number,url`), `--since <дата>` или `--all` — `gh pr list --author "@me" --state all --limit 200 --json number,title,createdAt,url` (`--since` — по `createdAt`). Без аргумента — спроси, не угадывай.

2. **Треды.** По каждому PR — `reviewThreads` через GraphQL (запрос — `resolve-pr-comments/references/steps.md`, «Команды GitHub») до конца; только треды, начатые не мной. Дедуп по журналу: `(project, pr, thread)` уже есть — пропустить, посчитать. Один-два PR разбирай сам по §3; пачку — сабагентом `general-purpose` с брифом §3 и дампом в файл (временный каталог сессии или `reports/` каталога тикета по `KEY` из заголовка PR), чтобы треды не оседали в контексте.

3. **Кандидаты.** Шаги 7.1–7.4 `resolve-pr-comments`: `rule_key`, сверка по §4 (журнал → чек-лист → `rules/general.md` → `CLAUDE.md` проекта и карта → память), список в формате §5. Для пачки кандидаты агрегируются по `rule_key` и показываются один раз с числом вхождений и списком PR; к новым тредам добавляются строки журнала с `decision: pending` того же проекта. Проектные (`project_specific`) — отдельной группой с адресом в `CLAUDE.md`/карте проекта; из worktree — текстом мне.

4. **Запись после «ок»** по каждому кандидату — как в шаге 7.4 `resolve-pr-comments`: плагин одним релизом на пачку, проект, память; журнал — строка по каждой новой находке и обновление `decision` у строк `pending`, отклонённые — `rejected:<почему>`.

5. **Сводка:** PR разобрано, тредов новых / уже в журнале, находок, повторов по `rule_key`, кандидатов, записано, отклонено, спорных.
