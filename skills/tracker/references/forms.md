# tracker — формы вывода

Таблицы markdown, не сырой JSON. Первая строка — шапка: проект, сколько задач, разбивка по стороне. В каждой строке задачи — «Про что» (summary, 40–50 символов). Статус и имена полей — как в YouTrack.

## Форма A — «Что в работе»

```
📋 T · нерешённых 7 · в работе 3 (back 2 · front 1)

| Задача | Про что | Сторона | Общая | Статус | Исполнитель |
|---|---|---|---|---|---|
| T-12 | Перенос урока: API | back | T-10 | В работе | Егор |
| T-16 | История оплат в карточке ученика: API | back | T-15 | Ревью | Егор |
| T-9 | Календарь на мобильном ломается | front | — | Бэклог | — |
```

Сортировка: сначала «в работе», потом остальные нерешённые; внутри — по дате обновления, свежие выше. Спросили про одну сторону — только её задачи; «Общая» — ключ родителя или `—`.

## Форма B — «Что зависло»

```
⏳ T · зависло 2 (без обновлений ≥ 5 дней)

| Задача | Про что | Сторона | Статус | Исполнитель | Обновлена | Последний комментарий |
|---|---|---|---|---|---|---|
| T-7 | Оплата уроков пакетом: API | back | В работе | Егор | 9 дней назад | «жду ответа по тарифам» |
```

«Последний комментарий» — суть в 5–10 словах из `get_issue_comments`; комментариев нет — `—`. Пусто — одна строка «зависших нет».

## Форма C — «Что по фиче»

```
🧩 T-10 · Перенос урока на другое время · В работе

| Подзадача | Сторона | Про что | Статус | Исполнитель |
|---|---|---|---|---|
| T-11 | front | Перенос урока: экран | Бэклог | — |
| T-12 | back | Перенос урока: API | В работе | Егор |
```

Первая строка — общая задача и её статус; ниже — подзадачи сторон. Подзадачи нет у одной из сторон — строка «front: подзадачи нет».
