# /tracker — read-only YouTrack

## Зачем

Тикет пересказывают по памяти: вложение со скрином никто не открыл, комментарий с уточнением прочитан наполовину, а «что в работе» собирают глазами по доске. Скилл берёт тикет целиком (поля, комментарии, файлы) и отдаёт короткие списки по стороне одной формой.

## Когда / когда нет

Когда: карточка и вложения тикета (зовёт `task-workflow`); «что в работе», «что зависло», «задачи бэка/фронта». Не для: записи в YouTrack — это отдельная просьба пользователя, MCP-инструмент записи, подтверждение хука `confirm-youtrack-write`; ведения тикета (`task-workflow`); учёта времени (его в devflow нет).

## 0. Конфиг проекта

`.claude/workflow.md` → «Тикет»: `key`, `project`, `side_field` (по умолчанию `Сторона`), `side` (сторона этого репозитория — «что в работе» без уточнения показывает её и «Оба»), `url`. Креды для вложений — `~/.claude/devflow/.env` (`YOUTRACK_URL`, `YOUTRACK_TOKEN`; `/devflow:setup`). Чтение — MCP-сервер YouTrack с именем `youtrack` (инструменты `mcp__youtrack__*`, схемы — `ToolSearch("select:mcp__youtrack__get_issue,…")`).

## 1. Протокол

- Только чтение: `get_issue`, `get_issue_comments`, `search_issues`, `get_issue_fields_schema`, `find_user`, `get_project`. Инструменты записи — не в этом скилле. `[хук]`
- Вложения — клиент `${CLAUDE_PLUGIN_ROOT}/skills/tracker/youtrack.mjs attachments` (у MCP нет скачивания файлов); файл с `error` назвать пользователю. `[слово]`
- Имена полей и значений (статусы, сторона) — из `get_issue_fields_schema` проекта, не по памяти. `[слово]`
- Зачёркнутое в описании и комментариях — закрыто. `[слово]`
- Рендер таблицей по форме, не сырым JSON; «про что» в каждой строке. `[слово]`

## 2. Этапы

| Запрос | Что вызвать | Вывод |
|---|---|---|
| карточка тикета (зовёт `task-workflow`) | `get_issue` + `get_issue_comments` (все страницы) | поля, описание, комментарии как есть |
| вложения | `node "${CLAUDE_PLUGIN_ROOT}/skills/tracker/youtrack.mjs" attachments --key <KEY> --out <каталог>` | JSON `{count, saved}` |
| «что в работе», «задачи бэка/фронта» | `search_issues`: `project: <project> #Unresolved` + сторона | форма A |
| «что зависло» | та же выборка, отбор по дате обновления | форма B |
| проверка доступа | `node …/youtrack.mjs check`; MCP — `get_current_user` | логин |

Запросы, сторона, «зависло» — `references/commands.md`. Формы A/B — `references/forms.md`.

## 3. Цикл

Агентов нет: единичное действие «запрос → форма».

## 4. Отчёт

```
📋 T · в работе 5 (бэк 3 · фронт 1 · оба 1) · зависло 1
| Задача | Про что | Сторона | Статус | Исполнитель | Обновлена |
| T-12 | Расписание занятий: перенос урока | Бэк | In Progress | Егор | 2 дня назад |
```

## Остановка

Пользователь после формы идёт в YouTrack смотреть то же самое — форма не отвечает на вопрос, пересмотреть `forms.md`. Вложения трижды подряд не скачались — проверить токен (`check`), не латать клиент.

## Самопроверка

- [ ] Тикет прочитан целиком: поля, все комментарии, вложения (честность).
- [ ] Поля и значения — из схемы проекта (честность).
- [ ] Файлы с ошибкой названы (честность; клиент их не прячет — тест).
- [ ] В YouTrack ничего не записано (машинно: инструменты записи ловит `confirm-youtrack-write`).
