# Task workflow — тикет от постановки до готовой ветки

## Зачем

Контекст тикета умирал с сессией. Пять ревью пропустили треть тестов сценариев (T-2121); ручной блок правил пропустил три правила (T-2122); план вырос молча. Скилл держит контекст в каталоге тикета и зовёт агентов по циклу.

## Когда / когда нет

Когда: фразы из описания. Не для: веток (`branch-ops`); чужого PR (`review-pr`); тредов своего PR (`fixes` → `resolve-pr-comments`).

## 0. Конфиг проекта

Первым делом `.claude/workflow.md` основного репозитория (из воркtree: `$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")/.claude/workflow.md`): все секции. Есть `.claude/skills/pw-task-workflow` — по нему. Нет файла — черновик по `references/workflow-template.md` после «ок», базу и проверки не угадывать. Из воркtree `.claude/` не правится — правку конфига отдай текстом с командой, куда положить.

## 1. Протокол

- Каталог тикета — `references/catalog.md` (в `.gitignore`, искать Bash); тикет эпика — `references/epics.md`. `[слово]`
- Находку, отклонение, развилку — датированной строкой в `reports/notes.md`. `[слово]`
- Размер по `Размер:` в `spec.md`, только растёт; карта области до плана; сценарии до кода. `[слово]`
- Решения и расширения — через `decision-critic`; на решение пользователя — аргумент, не «ок». `[слово]`
- Пуш, сквош, PR — только D `branch-ops` по команде; коммиты — оркестратор, явные пути. `[хук]`
- Агент не находится — перезапустить сессию; после `finish`/`fixes` — ретро. `[слово]`

## 2. Режимы

Определи режим по сообщению и прочитай только его справочник.

| Сообщение | Режим | Справочник |
|---|---|---|
| новая задача, изучи, проверь постановку | new-ticket | `references/new-ticket.md` |
| добро, начинай, делай | start → implement → finish | `references/start.md`, `references/implement.md`, `references/finish.md` |
| правки по ревью, тестер переоткрыл, баг, упал CI, вернись к | fixes | `references/fixes.md` |
| хочу посмотреть, подними стенд/локально, останови и почисти | show | `references/show.md` |
| на оценку, дай часы | estimate | `references/estimate.md` |
| исследуй, ресёрч, что нужно чтобы, сравни что есть / чего не хватает | research | `references/research.md` |
| что по статусу <KEY>, сделали или нет | status | `references/status.md` |
| новый эпик, статус эпика, какие эпики | epics | `references/epics.md` |

Воркtree — `references/worktree.md`; брифы — `references/brief.md`; текст команде — `references/team-report.md`.

## 3. Цикл

`references/cycles.md` — обязательные агенты по режимам (`spec-critic`, `system-mapper`, `quality-reviewer`, `black-box-tester`, `decision-critic`); Stop-хук `cycle-check.py` блокирует ход без них один раз.
