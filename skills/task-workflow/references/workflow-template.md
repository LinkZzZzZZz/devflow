## База знаний
- architecture_dir: `docs/architecture`
- architecture_ignore: `tests/**, migrations/**, fixtures/**`
- В шаблонах `architecture_ignore` и `paths:` карт `*` пересекает `/` (как в остальных полях плагина): `src/Billing/**` и `src/Billing/*` покрывают всё дерево.
- Карты модулей строит и сверяет `system-mapper` (шаги start/finish, `/devflow:map`); гейт пуша требует карту по `paths` для каждого файла ветки, кроме `architecture_ignore`, и строку `сверено` (коммит, после которого файлы модуля не менялись; сквош переживает). Без `architecture_dir` гейт молчит.
- Локальная база знаний (карты не попадают в git проекта): каталог в `.git/info/exclude` и в `.claude/worktree-links` (симлинк в каждый worktree, как `docs/tasks`); такая карта одна на все worktree и описывает базовую ветку: гейт считает её устаревшей, только если модуль менялся в базе после `сверено` (база — merge-base ветки с `origin/<base>`, коммиты ветки на соседних ветках origin её не сдвигают; карта новее этой точки — свежая); правки тикета в карту модуля не пишутся, finish оставляет их в `feature-map.md`, карта подтянет их на следующем тикете по модулю.
