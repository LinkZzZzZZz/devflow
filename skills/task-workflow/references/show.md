# show — показать результат

Триггеры: «хочу посмотреть», «подними стенд/локально», «дай креды»; «останови», «почисти».

1. Поля «Локальный стек» из `workflow.md`. Пусто — спроси у пользователя команды и допиши в конфиг после «ок» (из воркtree — отдай текст пользователю, см. `SKILL.md` §0).
2. Проверь, не поднят ли уже (порт из `app_url`, `docker ps`), иначе `stack_up` в фоне и дождись готовности (запрос к `app_url`).
3. `seed_user` — создай тестового пользователя и данные сценария из `spec.md`; запиши, что создано, в `reports/notes.md` (нужно для уборки).
4. Пользователю: адрес, логин/пароль тестового пользователя, по шагам — что открыть, чтобы увидеть изменение тикета.
5. По команде «останови/почисти»: `cleanup` (только то, что создано в шаге 3), `stack_down`. Проверь, что порт свободен.

Креды — только тестовые, созданные здесь или из сидов проекта. Чужие и боевые не вводить и не выводить.
