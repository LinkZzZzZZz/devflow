# worktree — параллельная работа

Заводится, когда параллельно идёт другой тикет и основной каталог занят. Если пользователь уже в нужной ветке — не заводить.

Имя воркtree = ключ тикета в нижнем регистре + суффикс по цели: `t-412`, `t-412-review`, `t-412-bug`. Один воркtree — один тикет: под другой тикет заводи новый (иначе day-track и track-time путают время).

Основной каталог: `MAIN=$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")`.

**При создании** симлинки на основной репозиторий ставит хук `$DEVFLOW_ROOT/hooks/worktree-links.py` — на старте сессии и в конце каждого хода; список путей — `$MAIN/.claude/worktree-links`. Руками симлинки не ставить. Зависимости и env — командой `worktree_setup` из конфига, в самом воркtree.

Если `<tasks_dir>` содержит отслеживаемые файлы, он симлинкается не целиком, а по папке на тикет. Новую папку тикета, созданную в воркtree, хук в конце хода переносит в основной репозиторий и заменяет симлинком.

Файлы тикета писать по пути воркtree (`<tasks_dir>/<KEY>/...`), а не по абсолютному пути основного репозитория: запись туда из worktree-сессии блокирует изоляция.

Проверить: `ls -la <tasks_dir>/<KEY> .claude/workflow.md` — симлинки. Сообщение хука «НЕ заменены симлинками» — в копии есть правки после создания воркtree: перенести их в основной репозиторий вручную.

Из worktree-сессии нельзя править `CLAUDE.md` и `.claude/` основного репозитория. Уроки и правки конфига — из сессии в основном каталоге; в воркtree подготовить текст и отдать пользователю.

**При завершении** — перед сносом проверить, что рабочая память тикета симлинкнута (иначе `git worktree remove` унесёт её):

```bash
cd "$MAIN"
WT=.claude/worktrees/<имя>
echo "{\"cwd\":\"$PWD/$WT\",\"hook_event_name\":\"Stop\"}" | $DEVFLOW_ROOT/hooks/worktree-links.py
while read -r p; do [ -z "$p" ] && continue; git ls-files --error-unmatch -- "$p" >/dev/null 2>&1 && continue; [ -e "$WT/$p" ] && [ ! -L "$WT/$p" ] && echo "НЕ СИМЛИНК: $p"; done < .claude/worktree-links
[ -L "$WT/<tasks_dir>" ] || for d in "$WT"/<tasks_dir>/*/; do
  d=${d%/}; git ls-files --error-unmatch "$d" >/dev/null 2>&1 && continue
  [ -L "$d" ] || echo "НЕ СИМЛИНК: ${d#$WT/} — перенести вручную"
done
```

Только если проверка ничего не вывела:

```bash
git worktree remove .claude/worktrees/<имя>
```

Ветка остаётся в репозитории; удаляется только рабочий каталог.
