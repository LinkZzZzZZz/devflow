# retro — записать подтверждённое

`$M` — память проекта (`candidates.md`: `M=~/.claude/projects/$(echo "$MAIN" | sed 's|[/._]|-|g')/memory`); между вызовами Bash переменная не живёт, задай заново.

## Шаг 5. Записать подтверждённое

Только то, что пользователь подтвердил явно.

- **Урок в память** — новый файл в `$M` по формату соседей (frontmatter `name`/`description`/`metadata.type`, тело с блоками `**Why:**` и `**How to apply:**`, связи `[[имя]]`), плюс строка в `MEMORY.md`.
- **Правило в `CLAUDE.md`** — императив с меткой, в подходящую секцию. Файл памяти при этом не удаляй: там остаётся обоснование, которому в `CLAUDE.md` не место, — сократи его тело до ссылки на секцию, сохранив `**Why:**` и `**How to apply:**`.
- **Дренаж** — правку `CLAUDE.md` делай только после подтверждения, что механика действительно на месте.
- **Правило в плагин** (`rules/general.md`, справочник скилла, агент) — только в рабочей копии `DEVFLOW_SRC` из `~/.claude/devflow/.env`, по шагам 4–5 команды `/devflow:rule`: правка → `tools/release.sh patch "<суть>" <файл>`. В каталоге плагина, загруженном из кэша (`~/.claude/plugins/`), не править.

Из воркtree запись в `CLAUDE.md` и `.claude/` основного репозитория запрещена — подготовь текст и отдай пользователю; память и репозиторий плагина писать можно.

В конце — короткая сводка: что записано, что отклонено, какие расхождения меток найдены, метрики шага 4а (согласий без аргумента, утверждений без критика, `impl.blind-edit`, вердикты критика).
